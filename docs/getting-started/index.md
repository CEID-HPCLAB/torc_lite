# Get started

Torc-Lite is distributed as source code built with GNU Autotools, C/Fortran toolchains and an MPI implementation.

The recommended first path is:

1. [Install](installation.md) Torc-Lite and its bundled demos.
2. Run the [master–worker example](first-program.md) with one process, then multiple MPI processes.
3. Read [task arguments](../concepts/arguments.md) to learn how inputs and results move between workers.
4. Browse the [source-backed example gallery](../examples/index.md) and [C API](../api/c.md).

!!! tip "Repository versus website"
    The source lives at [`CEID-HPCLAB/torc_lite`](https://github.com/CEID-HPCLAB/torc_lite); this website is its programming guide, API reference, and research overview.
